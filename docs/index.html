1. Smart Note Vault & Computer Vision

On-device Laplacian variance computation (threshold = 85.0) filters blurry classroom photos before storage. 64-bit dHash, pHash, and SSIM avoid duplicates. Timetable priors automatically file notes under their corresponding subject.

2. Lock-Screen Attendance Logging

Powered by Android WorkManager. Periodic background workers dispatch interactive notification action buttons ([Yes, Attending], [No, Bunking], [Class Cancelled]) updating Room SQLite without opening the app.

3. Clean Unicode Math AI

Eliminates raw unrendered LaTeX backslash clutter. Powered by Gemini 2.5 Flash, generating clean mathematical symbols for instant readability during quick exam revisions:

System Architecture & Tech Stack

EngBuddy combines modern mobile and cloud technologies into an offline-first architecture:

  • Native Android Client: Kotlin 2.0, Jetpack Compose Material 3, Room SQLite, WorkManager, Retrofit 2 + Moshi.
  • Backend Cloud Services: Python 3.12, FastAPI, SQLAlchemy 2 (AsyncIO), Celery worker pool, Redis 7 message broker.
  • Storage & Retrieval: PostgreSQL 16 with pgvector extension (HNSW vector similarity indexing for RAG) and MinIO S3 object store.
  • Generative AI: Google Gemini 2.5 Flash API with strict formatting system prompts.
